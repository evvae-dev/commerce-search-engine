# 상품 조회 API

`GET /api/v1/goods/{goodsId}`는 가상 상품 번호로 문서를 조회합니다. 예: `/api/v1/goods/DEMO0001`.

`GET /api/v1/goods?exhbtNo=1&thmNo=1&page=1&size=10`은 가상 기획전·테마에 속한 상품을 조회합니다. 초기화 시 `DAY_ORDER`를 가상 일일 판매량순으로 등록합니다. 예제 상품에는 기획전 `1`, 테마 `1` 또는 `2`를 넣었습니다. 정렬은 관리자 검색정렬에서 편집할 수 있습니다.

상품 검색은 `/api/v1/search?q=재킷&page=1&size=10`입니다. 응답은 상품과 페이징 정보이며 점수·형태소 진단은 관리자 시뮬레이터에서 확인합니다.
